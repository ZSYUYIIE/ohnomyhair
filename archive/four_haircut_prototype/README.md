# Retired four-haircut prototype

Archived on 2026-10-18 after the two-friend escape story was selected.

Afro's spring overlapped Pompadour's launch role, and Afro / Long Straight introduced
different-looking characters and training chapters outside the chase. The playable game
now follows Twin-Tails and Pompadour only.

This folder preserves source sheets, normalized sprites and portraits, ability scripts,
Perm Day, Extensions, Style Lab, their builders and tests. Original relative paths are
retained under this folder for reference. They are historical snapshots, not runnable
scenes against the current two-haircut APIs. Git history preserves the full prototype.

`.gdignore` excludes the folder from Godot's resource scan and game export. Restoring
these concepts would require a new design and art pass against the original characters.
