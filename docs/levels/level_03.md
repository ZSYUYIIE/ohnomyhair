# L3「理发师」：打烊时间

> 对应 [PLAN.md](../../PLAN.md) 1.4 节 L3 + 1.5 节 Something's Off。三个单屏房间，预计 3–5 分钟。
> 场景由 `tools/build_level_03.gd` 生成（重新运行会覆盖场景），测试是 `tests/test_level_03.gd`。
>
> **一句话**：把 L1 的带人飞和 L2 的弹反放到一起用；中途两人发型互换，再用换过来的能力打理发机器人。

## 1. 三个房间

| 房间 | 考什么 | 解法 |
|---|---|---|
| **1 打烊时间** | 带人飞 + 弹反，在压力下一起用 | 发射器（第 38 列第 16 行，每 3 秒一把）沿起飞台高度射剪刀。B 在起飞台上把剪刀弹回去，发射器卡住 3 秒，趁空中没有剪刀时 A 带 B 飞过 9 格的染发剂池。**被带着飞的人也能弹反**（L）。落地后有一只电推剪：甩发眩晕，冲刺撞碎。 |
| **2 理发椅**（Something's Off） | 适应互换后的能力 | 天花板压低的通道里有一把理发椅，**第一个人走进去时两人的发型立刻互换**：颜色、技能、攻击全部跟着换，HUD 也会更新。互换后的说明到这时才显示，不会提前剧透。之后 **P1（现在是前刺）** 冲刺撞墙、把 P2 弹上悬崖；**P2（现在是双马尾）** 拉拉杆让台阶升起。 |
| **3 理发机器人**（Boss） | 弹反 + 弹射 / 平台下落踩头 | 见第 2 节。打败后右边的门打开，两人进出口后显示结局文字。 |

## 2. Boss：理发机器人（`scenes/enemies/barber_bot.gd`）

有限状态机，每个状态是一个函数，返回下一个状态：

```
WALK（和最近的玩家保持约 6 格距离）──→ 交替：SHOOT（连发 3 把剪刀）/ WINDUP（闪白 0.7 秒）→ CHARGE（冲撞）
CHARGE 撞墙 ─→ DAZED 2 秒        被弹回的剪刀打中 ─→ DAZED 4 秒
DAZED 时有人落在头顶旋钮上 ─→ HP-1 → HURT 0.8 秒 → WALK；HP 归零 → DEAD（发出 defeated 信号，门打开）
```

- **只有“踩头”能造成伤害**：甩发、冲刺、弹反挥击对它都无效（“太大了”）。HP 3。
- 剪刀飞在玩家身体的高度：前刺可以弹反，跳起来也能躲开。
- 走路和冲撞时碰到玩家会扣 1 血并击退；晕倒时不会。踩头的人有 1.2 秒无敌，避免落地马上挨打。
- **两种踩头路线**：
  1. 弹反把它打晕 4 秒 → P2 站在 P1 头上，P1 驮着 P2 走过去（站在头上的人会跟着走）→ P1 按 G 弹射 → P2 飞到它头顶，按住 K 滑翔落到旋钮上。
  2. 引它冲撞撞墙，它会晕在墙角平台下面 → 站在墙角平台上的人**按住 ↓ 穿过平台**落下去。
- 场地中间没有平台，弹射不会被挡住。

## 3. 关键数值

| 量 | 数值 | 说明 |
|---|---|---|
| 房间 1 染发剂池 | 9 格 | 从高 2 格的起飞台带人飞能飞 11.4 格；B 自己跳只有 7.0 格 |
| 房间 1 发射器间隔 | 3.0 秒 | 原来是 2 秒，空中常有 2 把剪刀，卡住发射器后还会被之前射出的打中，太乱 |
| Boss 高度 | 4 格 | 普通跳 3.56 格够不到头顶，必须弹射或从高处落下 |
| 弹射高度 | 头顶以上 8 格 | |
| Boss 眩晕 | 弹反 4 秒，撞墙 2 秒 | 4 秒刚好够驮人走过去再弹射 |

## 4. 可调参数（试玩时只动这些）

## 5. 试玩要观察的

- 玩家有没有自己想到“被带着的时候弹反”？没有也能过，这是给会玩的人的加分操作。
- 发型互换那一刻，两个人有没有笑或者喊出来？这是 Something's Off 的核心时刻。如果他们没注意到，就把闪屏加长，或者暂停 1 秒。
- 打 Boss 时是“驮过去弹射”用得多，还是“墙角平台落下”用得多？如果两种都没人想到，就把提示牌写得更直白。
