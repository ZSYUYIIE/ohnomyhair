# L3「洗吹一条龙」：Wash & Blow-Dry

> 三个单屏房间，预计 3–4 分钟。放在 L2（接力扣杀）和 L4（理发机器人 Boss）之间。
> 场景由 `tools/build_level_03.gd` 生成（重新运行会覆盖场景），测试是 `tests/test_level_03.gd`。
>
> **一句话**：吹风机的热风把滑翔的双马尾往上托；洗头花洒会把头发淋湿，湿了的双马尾不能滑翔、湿了的前刺撞不碎发胶；吹风机一吹就干。

## 1. 新机制

| 机制 | 规则 | 文件 |
|---|---|---|
| **吹风机（上升气流）** | 一根暖风柱。**正在滑翔**的双马尾会往上升（300 px/s），到柱顶附近上下浮动；**吊着队友**时太重，只能悬停不动；其他人在风里下落变慢。站进风里立刻吹干。 | `scenes/props/hair_dryer.gd` |
| **新组合技：发型直升机（Hair-copter）** | 前刺**站在双马尾头上**，双马尾在吹风机里滑翔，把前刺一起带上去。前刺到高处再跳到平台上。（站在头上时按技能是滑翔，不会误抓队友。） | `player.gd` 里“头上的人跟着一起升” |
| **洗头花洒（淋湿）** | 定时喷水（关 1.8 秒，闪水滴预警，喷 1.6 秒），站在下面会湿 8 秒。**湿了的双马尾**：马尾太重，不能滑翔。**湿了的前刺**：发型塌了，冲刺撞到发胶会弹开。 | `scenes/props/shower_head.gd` |
| **生发水** | 绿瓶子，捡到回 1 格头发（1 HP）；满血的人不会捡走，留给队友。重开房间时会回来。 | `scenes/props/growth_tonic.gd` |
| **头发就是血量** | 每挨一下，头上就飞出一撮剪下来的头发（发型颜色），HUD 少一颗心。角色改用精灵图后不能再把头发画短，所以用“剪落”的效果表示。 | `player.gd` 的 `HairSnip` |

## 2. 三个房间

| 房间 | 考什么 | 解法 |
|---|---|---|
| **1 吹风吧**（教） | 吹风机单人上升 → 发型直升机 | 左边的吹风机把 P1 托到 10 格高的架子上，拉杆抬起闸门让两人通过。右边出口平台高 11 格：吊着 P2 进风里只能悬停（提示：“太重了！P2 站到 P1 头上”），所以 P2 站上 P1 的头，P1 起跳滑翔，两人一起升上去，P2 先跳上平台，P1 再飘过去。 |
| **2 洗头台**（教） | 淋湿的两种后果 + 吹干 | 起飞台上方有定时花洒：被淋湿的双马尾带不动人，必须等花洒停了再起跳吊运过染发剂池（10 格，从 2 格高的台子起飞）。对岸的发胶前面又有一个定时花洒：湿着去撞发胶会弹开，要退回花洒**前面**的吹风机吹干，再趁花洒停的时候冲过去撞墙。 |
| **3 冲水再来**（考） | 全部一起 | 吹风机柱顶上有定时花洒：要趁停喷时用发型直升机上到上层平台，在柱顶磨蹭会被淋湿掉下去。平台上有生发水、一个小吹风机（顺路吹干）、发胶墙，发胶后面藏着剪刀发射器：撞开发胶后，P2 要弹反让它卡住，两人再进出口。 |

## 3. 关键数值

| 量 | 数值 |
|---|---|
| 吹风机上升速度 / 加速度 | 300 px/s / 1800 px/s² |
| 风里非滑翔者的最大下落速度 | 260 px/s |
| 花洒周期 | 关 1.8 秒（最后 0.6 秒滴水预警）、喷 1.6 秒；L3-R3 柱顶花洒关 2.2 喷 1.4 |
| 淋湿持续 | 8 秒（站进吹风机立刻干） |
| 生发水 | +1 HP，最多 3 |

## 5. 试玩要看的

- R1：玩家会不会先试“吊着飞上去”，失败后想到“站到头上”？提示够不够？
- R2：第一次被淋湿时，玩家能不能看出是“湿了”导致不能滑翔（水滴特效 + 头发变暗变塌）？
- R3：柱顶花洒的时机会不会太紧（目前从地面起飞到上平台约 1.5 秒，停喷 2.2 秒）。

## 6. 美术（和 L1 的涂鸦风格统一）

- 新机关的图由 `tools/art/make_salon_props.py` 生成，直接复用 `make_l1_art.py` 的抖动墨线和平涂：吹风机（珊瑚色，P1 的粉色留给玩家）、花洒头、生发水瓶、加热直板夹（冷 / 烫两帧）。
- 会动的部分仍然由代码画：吹风机的暖风、花洒的水流和预警水滴、生发水的上下浮动和闪光、直板夹的蒸汽。
- 角色精灵上的效果：淋湿时整个精灵变成偏冷的浅蓝色并滴水；双马尾接住剪刀时用举手的 `pull` 姿势，剪刀举在头顶。
- 还没做：L2–L4 的地砖和背景仍然是灰盒地砖 + `SalonDecor` 墙面（美术文档里列为下一步）。
