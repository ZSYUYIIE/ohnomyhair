# L3「洗吹一条龙」：Wash & Blow-Dry

> 三个单屏房间，预计 3–4 分钟。放在 L2（接力扣杀）和 L4（理发机器人 Boss）之间。
> 场景由 `tools/build_level_03.gd` 生成（重新运行会覆盖场景），测试是 `tests/test_level_03.gd`。
>
> **一句话**：吹风机的热风把滑翔的双马尾往上托（吊着队友也能升，只是慢一些）；洗头花洒会把头发淋湿几秒，湿了的双马尾不能滑翔、湿了的前刺撞不碎发胶；吹风机一吹就干。
>
> 第 5 次试玩后重做了 R2 和 R3，原因见 [refinement.md 第 9 节](../design/refinement.md)。

## 1. 机制

| 机制 | 规则 | 文件 |
|---|---|---|
| **吹风机（上升气流）** | 一根暖风柱。**正在滑翔**的双马尾往上升（300 px/s），到柱顶附近上下浮动；**吊着队友**也能升，160 px/s；其他人在风里下落变慢。站进风里立刻吹干——但**正在喷的花洒压过吹风机**，淋着就一直是湿的。 | `scenes/props/hair_dryer.gd` |
| **发型直升机（Hair-copter）** | 前刺**站在双马尾头上**，双马尾在风里滑翔，两人以全速（300 px/s）一起上去。比吊着上去快一倍，是高手的选择，不是必须。 | `player.gd`“头上的人跟着一起升” |
| **洗头花洒（淋湿）** | 定时喷水（停喷的最后 0.6 秒有水滴预警），淋到的人湿 **4 秒**，头顶出现“水滴 + 圆环”倒计时，时间到自己就干。**湿了的双马尾**：不能滑翔，所以也不能吊人飞。**湿了的前刺**：冲刺撞发胶会弹开。 | `scenes/props/shower_head.gd` |
| **前刺空中冲刺** | 每次跳跃在空中只能冲刺一次，落地恢复（被甩出也算这一次）。以前每次空中冲刺都会把下落速度清零，连按就能飘过任何坑，吊运就被跳过了。 | `pompadour.gd` |

生发水和头发血量仍在游戏里（L4 用得上），但 L3 没有伤害来源，所以 L3 不放生发水。

## 2. 三个房间

| 房间 | 考什么 | 解法 |
|---|---|---|
| **1 吹风吧**（教） | 吹风机单人上升 → 吊着队友上升 | 左边的吹风机把 P1 托到 10 格高的架子上，拉杆抬起闸门。右边出口平台高 11 格：P1 抓住 P2，跳进大吹风机里按住 G，两人慢慢升上去，再滑到平台上。提示里顺带说“P2 站在 P1 头上会更快”。 |
| **2 洗头台**（教） | 淋湿的两种后果 + 自然干 / 吹干 | 9 格高的起飞台上方有定时花洒。P2 可以先站上去（湿了也无所谓，被吊的人不用滑翔）；P1 在台阶上等花洒停，再上台抓住 P2，飞过 **17 格**的染发剂池。P1 被淋湿了也不用重开：下台阶等 4 秒就干。对岸：发胶前面还有一道定时花洒，湿着撞发胶会弹开，要退回花洒前面的吹风机吹干，再趁停喷冲过去。 |
| **3 冲水再来**（考） | 吹风机 + 花洒，各考一次 | **上**：吊着 P2 在吹风柱里往上升，花洒横穿柱子的中上段。正在喷时进去会被淋湿、掉回风里、立刻吹干再往上，所以玩家自然学会在花洒下面等空档，停喷就一口气升上去（约 2.4 秒，停喷 3 秒）。**下**：从 12 格高的平台吊着 P2 飞过 **18 格**的染发剂池，池子中间有定时花洒，飞过去时正在喷就会湿、掉进池子，所以要在刚停喷时起飞。 |

## 3. 关键数值（`tools/measure_metrics.gd` 和逐帧暴力搜索实测）

| 量 | 数值 |
|---|---|
| 吹风机上升速度：单人 / 吊人 / 发型直升机 | 300 / 160 / 300 px/s |
| 花洒周期 | R2 起飞台：停 1.8、喷 1.6；R2 对岸：同上，错开 0.9 秒；R3 柱子：停 3.0、喷 1.4；R3 池子：停 2.6、喷 1.2 |
| 淋湿持续 | 4 秒（站进吹风机立刻干，除非花洒正淋着） |
| 前刺单人能跨的坑（一次地面冲刺 + 起跳 + 一次空中冲刺，最佳时机） | 6 格落差 13.1 格，9 格落差 14.2 格，12 格落差 15.0 格 |
| 吊运能跨的坑 | 6 格落差 15.7 格，9 格落差 19.6 格，12 格落差 23.4 格 |
| R2 / R3 染发剂池 | 17 格（9 格落差） / 18 格（12 格落差） |

坑的宽度都选在“前刺单人上限”和“吊运下限”之间，两边至少留 1.8 格。

## 4. 自动测试覆盖

`test_level_03.gd`（27 项）：三个房间完整通关；反例：
- R2、R3 前刺单人按最佳时机冲刺都过不去；
- R2 起飞台上被淋湿不能滑翔，下台阶 4.5 秒内自己干；
- R3 在花洒快开时起飞，吊运会被淋湿掉进池子。

`test_combos.gd`：吊人在风里上升且比单人慢、发型直升机、花洒压过吹风机、每次跳跃只能空中冲刺一次、湿前刺撞不碎发胶等。

## 5. 试玩要看的

- R1：玩家会不会自然地“吊着队友飞进风里”？有没有人发现站头上更快？
- R2：P1 被淋湿后，头顶的倒计时有没有让玩家明白“等一下就好”？
- R3 上：在花洒下面“等空档”是不是一看就懂？会不会有人觉得被弹来弹去很烦？
- R3 下：起飞时机会不会太紧？太紧就把 `PoolShower` 的停喷时间从 2.6 调到 3.0。

## 6. 美术（和 L1 的涂鸦风格统一）

- 新机关的图由 `tools/art/make_salon_props.py` 生成，复用 `make_l1_art.py` 的抖动墨线和平涂：吹风机（珊瑚色，P1 的粉色留给玩家）、花洒头、生发水瓶、加热直板夹（冷 / 烫两帧）。
- 会动的部分由代码画：吹风机的暖风、花洒的水流和预警水滴、淋湿的水滴和倒计时圆环。
- 地砖和三个房间的墙面由 `tools/art/make_world_art.py` 生成：吹风吧、洗头台、冲水间。
