# L2「原路奉还」：接发抛

> 对应 [PLAN.md](../../PLAN.md) 1.4 节 L2。两个单屏房间，预计 2–3 分钟。
> 场景由 `tools/build_level_02.gd` 生成（重新运行会覆盖场景），测试是 `tests/test_level_02.gd`。
> 为什么改：见 [docs/design/refinement.md](../design/refinement.md)。旧版用“拉杆 → 反射板”折射剪刀，
> 剪刀是被铁板打上去的，不是被头发打上去的。旧版设计在 git 历史里。
>
> **一句话**：前刺把剪刀**弹反**成蓝色，双马尾蹲在沟里张开马尾**接住**蓝色剪刀，松手往上**抛**，打响天花板上的服务铃。
>
> **第 3 次试玩后改名**：原来叫“接力扣杀（Volley）”，是双马尾用甩发把剪刀打上去，玩起来像第二个弹反。现在**只有前刺会弹反**，双马尾改成用她的招牌动作——用头发**抓**。

## 1. 新组合技：接发抛（Hair Catch）

| 步骤 | 谁 | 细节 |
|---|---|---|
| 1. 弹反 | 前刺（攻击键） | 0.15 秒判定。剪刀反向飞回，变成**蓝色**（`player_attack` 层），速度 ×1.5。 |
| 2. 接住 | 双马尾（**站在地上**按住技能键） | 按住时马尾张开（在空中按住只是滑翔，不会接，免得 Boss 战里把队友弹给 Boss 的剪刀抢走），范围包括**头顶上方**（左右各 52px、头顶以上 84px）。蓝色剪刀飞进来就被接住，举在头顶转。红色（敌方）剪刀接不住，照样会伤人。甩发（攻击键）完全碰不到剪刀。 |
| 3. 抛 | 双马尾（**松开**技能键） | 剪刀从双马尾的位置**笔直向上**，变**金色**，速度 ×2。 |
| 4. 打铃 | — | 金色 / 蓝色剪刀打中服务铃 → 铃响（锁存）→ 员工门打开。 |

- **沟**：地面上 1 格宽、2 格深的坑，地面画了粉色条纹。双马尾站在沟里，头顶比剪刀线低，**敌方剪刀从头上飞过伤不到她**，但张开的马尾仍然接得到头顶飞过的蓝色剪刀。
- **黄色条纹**：前刺弹反的位置，在沟的左边（剪刀从右边来）。站在沟右边弹反，弹回的剪刀不会经过沟。
- 缺一个人就做不到：前刺单独弹反只会让发射器卡住 3 秒；双马尾接不住敌方剪刀（只会挨打）。
- 和旧版比：不再需要掐 0.12 秒的甩发时机，提前按住就行，节奏压力全在前刺的弹反上。

## 2. 两个房间

| 房间 | 考什么 | 布局与解法 |
|---|---|---|
| **1 原路奉还**（教） | 先学弹反，再学接发抛 | 剪刀发射器在右墙第 18 行（身体高度）。沟在 x=20，服务铃在它正上方的天花板。P2 在黄色条纹（x=8–18）上弹反，第一次单独弹反只会让发射器冒烟卡住，铃不响。P1 进沟接住再抛上去后铃响，员工门（x=32）打开。之后踩三层墙上置物架（单向平台，间隔 3 格）上到出口。 |
| **2 剪刀走廊**（考） | 两个铃 + 小兵挡路 + 护送 | 原来的走廊，去掉了拉杆、高台和反射板。走廊上 x=22 和 x=30 各有一个沟，各对着一个铃，**门要两个铃都响**。两个沟之间有一只电推剪巡逻：它会挡住飞向远处沟的蓝色剪刀，要先处理掉（P1 让两把蓝色剪刀飞过去打它，或者冲刺 / 眩晕）。P1 在走廊上移动时暴露在剪刀线上，所以 P2 要先弹反一次让发射器卡住，再让 P1 换沟。 |

## 3. 关键数值

| 量 | 数值 |
|---|---|
| 敌方剪刀速度 / 弹反后 / 金色 | 240 / 360 / 480 px/s |
| 发射间隔 | 2.5 秒；开火前 0.4 秒红灯闪 |
| 弹反卡住发射器 | 3 秒 |
| 接住范围 | 左右各 52px、头顶以上 84px（按住技能键期间一直有效） |

## 4. 试玩要看的

- 两个人有没有喊“弹了！”“接住！”。双马尾会不会忘了要**松手**才会抛。
- 第 2 间：玩家会不会想到“先让发射器卡住再换沟”。想不到的话，在走廊上加一句提示。
