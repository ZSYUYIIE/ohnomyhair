# L2「弹反合作」：剪刀走廊

> 对应 [PLAN.md](../../PLAN.md) 1.4 节 L2。单屏固定镜头，预计通关 60–90 秒。
>
> **一句话**：B 在走廊上把剪刀弹回去，A 在高台上掐准时机拉杆，让反射板把剪刀折射到天花板的开关上。

## 1. 这一关要教会什么

| 新东西 | 谁 | 怎么教 |
|---|---|---|
| **弹反** | B（前刺） | 剪刀从右边飞来，B 一弹，剪刀飞回去打中发射器，发射器冒烟卡住 3 秒。玩家自己就能看懂。 |
| **人肉弹射** | A 站在 B 头上，B 按技能 | 拉杆在一个普通跳跃够不到的高台上，只能靠弹射上去。 |
| **弹反定向**（组合技 3） | 两人同时 | 拉杆不是开关，是**弹簧拉杆**：拉一下，反射板只竖起 1.2 秒。A 必须看着 B 什么时候弹反再拉。 |
| 战斗练习 | 两人都行 | 开局一只电推剪机器人。一个人也打得过，两个人配合（A 眩晕 + B 冲撞）更快。 |

L1 已经教过滑翔、冲撞和马尾吊运；这一关只在离场时顺便用一下滑翔，不再考吊运。

> PLAN.md 的 L1 里没有教人肉弹射，所以放在这一关第一次出现。L3 再把两个组合技放在压力下连用。

### 2.1 分区和流程

1. **开局区（x1–12，地面）**：两人出生在左下。电推剪机器人在 x5–11 来回巡逻（`patrol_range = 48`，别碰到出生点）。剪刀从头顶的 14 行飞过去，打不到地面上的人，但能让玩家先看到发射器。
2. **台阶（x13–16）**：两级各 2 格高的台阶。台阶顶上有检查点 `k`，在剪刀线下面，复活时不会马上被打。
3. **走廊（x17–34，第 15 行）**：剪刀沿第 14 行从右往左飞，正好打中站在走廊上的人。
   - B 站在反射板**左边**（x17–27）弹反；站在右边弹，剪刀不经过反射板，只会打回发射器。
   - B 站在拉杆高台正下方（x18–21），A 跳到 B 头上，B 按技能把 A 弹上高台。
4. **拉杆高台（x17–22，第 7 行，单向平台）**：A 在这里拉弹簧拉杆。
5. **开门后**：两人从走廊右端跳到右侧平台（x35–38），再往左走下平台落到地面，从走廊底下向左走，过门进入出口 `E`。A 从高台上滑翔到走廊上即可。

### 2.2 解法（玩家视角）

1. 打掉电推剪（或者绕开），走上台阶。
2. B 被剪刀打一两下，试着弹反，发现剪刀会飞回去让发射器卡住。
3. 两人看到高台上的拉杆。A 跳不上去 → B 站到高台下面，A 跳到 B 头上，B 按技能，A 被弹上去。
4. A 拉一下拉杆，反射板竖起来，过一会儿又倒下。两人要商量：“我弹的时候你拉！”
5. B 弹反，A 同时拉杆，剪刀飞回去撞上竖起的反射板，转 90° 向上，打中天花板的开关，门打开。
6. 两人下到地面，从走廊底下走进出口。

## 3. 关键数值（全部按 PLAN.md 2.5 的手感参数算）

| 量 | 数值 | 用在哪里 |
|---|---|---|
| 普通跳高 | 56px = 3.5 格 | 所有台阶都是 2 格高；右侧单向平台到走廊是 3 格（较紧，见 6 节） |
| 平地跳远 | 约 85px = 5.3 格 | 本关没有需要跳的坑 |
| 人肉弹射上升 | 143px ≈ 9 格（从 B 头顶起跳） | A 起跳时脚在 y=216，最高到 y≈73；高台顶面 y=112，**余量 39px** |
| 站在 B 头上普通跳 | 最高到 y=160 | 够不到高台（y=112），所以**只有弹射能上去** |
| 剪刀速度 | 120 px/s | 从发射器飞到 B（约 18 格）≈ 2.4 秒，看得清 |
| 发射间隔 | 2.5 秒 | 同时最多 2 把剪刀在空中 |
| 弹反后剪刀速度 | 180 px/s（×1.5） | 从 B（x≈20）飞到反射板（x=28）≈ 0.7 秒 |
| 反射板竖起时长 | 1.2 秒 | A 在 B 弹反前 0.5 秒到弹反后 0.7 秒之间拉都能成功 |
| 发射器被打中卡住 | 3 秒 | 弹反失败的反馈，不是惩罚 |
| 剪刀伤害 | 1（HP 3） | B 可以失误两次 |

## 4. 需要的部件和接口

和 PLAN.md 2.3 的碰撞层、2.6 的接口保持一致。

| 部件 | 负责人 | 说明 |
|---|---|---|
| `scissor_turret` | Dev B | `@export var interval := 2.5`、`speed := 120.0`、`direction := Vector2.LEFT`。实现 `take_hit(damage, stun_time, knockback)`：被弹回的剪刀打中时按 `stun_time` 卡住（冒烟、不发射）。 |
| `scissor` | Dev B | Area2D。默认 layer 5 `enemy_attack`，mask `players`。`deflect()`：方向反转、速度 ×1.5、layer 改成 4 `player_attack`、mask 改成 `enemies + interactables`。`redirect(dir)`：只改方向。撞到 `world` 就消失。 |
| `deflector`（反射板） | Dev B | Area2D，layer 6，**mask 只有 4 `player_attack`**，所以飞来的敌方剪刀会直接穿过去，只有弹回的剪刀会被折射。`raise()` / `lower()`；竖起时对进来的剪刀调用 `redirect(Vector2.UP)`。 |
| `lever`（弹簧模式） | Dev B | 在现有拉杆上加 `@export var spring_time := 0.0`：0 = 普通开关，大于 0 = 拉下后这么多秒自动弹回。拉下发 `activated`，弹回发 `deactivated`。 |
| `switch`（被击开关） | Dev B | Area2D，layer 6，mask 4。第一次被弹回的剪刀打中就发 `activated` 并一直保持（锁存），然后删除剪刀。 |
| `door` | Dev B（L1 已有） | 连 `switch.activated`。 |
| 单向平台 | Dev B | TileSet 里给瓦片开 one-way collision。高台和右侧平台都用它。 |
| 弹反、人肉弹射 | Dev A | 见下面第 5 节的两个依赖。 |

编辑器里的连线：

```
lever.activated    → deflector.raise
lever.deactivated  → deflector.lower
switch.activated   → door.open
```

## 5. 和 Dev A 要先对齐的两件事

1. **A 怎么站到 B 头上**：PLAN.md 只写了 `HeadPad (Area2D)`，它只能检测，不能让人站上去。两个玩家互相碰撞又会在走廊里互相挡路。建议在 B 头顶加一个 `AnimatableBody2D`，碰撞形状开 one-way，这样 A 能从下面跳上来站住，横着走不会被挡。
2. **弹射不能被“短按小跳”砍掉**：PLAN.md 2.5 里松开跳跃键会把向上速度 ×0.45。如果 A 被弹射时刚好松开跳跃键，高度会从 9 格掉到 4 格左右，上不了高台。被弹射时要设一个标记，这次上升期间忽略短按小跳。

## 6. 防卡死检查

| 情况 | 结果 |
|---|---|
| 开门前有人从走廊右端掉到地面 | 右侧单向平台（第 18 行）可以跳回走廊。平台比地面高 3 格、比走廊低 3 格，都在 3.5 格跳高之内但余量只有 8px；试玩时太难就把平台改成两级。 |
| A 在高台上，B 死了 | 两人一起回到检查点 `k`，A 需要重新被弹射上去。开关和门的状态保留。 |
| 剪刀打到 A | 不会：剪刀在第 14 行，高台和 B 头顶都在剪刀线上方。弹回的剪刀是 `player_attack`，不伤玩家。 |
| 不用反射板也能打中开关吗 | 不能：弹反只会让剪刀水平飞回去，开关在正上方。 |
| 绕过门进入出口 | 不能：出口三面是墙，上面是走廊（实心）。x17 那一列从第 16 行到地面都是墙。 |
| 折射向上的剪刀没打中开关 | 第 28 列从第 2 行到第 13 行全空，一定会打中；万一偏了，撞到天花板消失。 |

## 7. 可调参数（试玩时只动这些）

| 参数 | 默认 | 太难就 | 太简单就 |
|---|---|---|---|
| `deflector` 竖起时长 | 1.2 秒 | 加到 2 秒 | 减到 0.8 秒 |
| 弹反判定窗口（Dev A） | 0.15 秒 | 加到 0.2 秒 | 不动 |
| 剪刀速度 | 120 | 降到 90 | 升到 150 |

## 8. 可选加分（MVP 之后，按顺序）

1. **Something's Off 伏笔**（只要一张图）：高台背景墙上挂一面镜子，A 照镜子时，镜子里的倒影是**前刺发型**。L3 发型互换时，玩家会想起这面镜子。
2. 开门后，走廊底下（x25–34）出现第二只电推剪，让离场多一点紧张感。

## 9. 试玩时要问的问题

- 没人提示的情况下，B 多久发现自己能弹反？超过 30 秒就在台阶上加一个按键提示牌。
- 两人有没有**开口商量**拉杆的时机？没有的话，说明反射板竖起时间太长，A 一直拉着就过了。
- 有没有人想到“站在队友头上弹射”？想不到就在高台下面加提示牌，比如画一个人叠人的图标。
