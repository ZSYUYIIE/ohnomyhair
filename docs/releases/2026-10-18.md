# Web build 2026-10-18

Built with Godot 4.7.2, release template, Compatibility renderer, single-threaded
WebAssembly. `export_presets.cfg` excludes tools, tests, docs, archives and source art.

Build from the repository root:

```powershell
python tools/release/fetch_web_template.py
godot --headless --path . --export-release Web build/web/index.html
Compress-Archive -Path build/web/* -DestinationPath build/oh_no_my_hair_web.zip -Force
```

The template downloader retrieves only the official single-threaded release template
from Godot's 4.7.2 archive, using ZIP byte ranges rather than downloading every platform.
The output ZIP contains `index.html` at its root. Preserve the existing itch filename
`oh_no_my_hair_web.zip` when updating the browser-playable upload.
